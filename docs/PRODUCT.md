# Product

## Register

product

## Users

Batwa serves customers, agents, merchants, and administrators at local
counter-based payment points. Agents register customers and load printed QR
cards, merchants accept payments, and administrators monitor the transaction
network. Users need short, understandable flows that work on ordinary
hardware without requiring a smartphone.

## Product Purpose

Batwa simulates assisted digital payments using a printed QR card and a PIN.
It turns cash-in, payment, card management, and transaction monitoring into
clear operational workflows with an auditable record of each result.

## Brand Personality

Clear, calm, human. The interface should reduce uncertainty at the counter,
make the next action obvious, and communicate failures without blame.

## Anti-references

Avoid generic fintech dashboards, dense enterprise admin panels, playful
consumer-app decoration, low-contrast text, and controls that change visual
language between roles or routes.

## Design Principles

- Make the next counter action obvious.
- Use familiar controls with consistent states.
- Keep important information readable in ordinary lighting.
- Treat failure and recovery as part of the normal workflow.
- Preserve the same interaction vocabulary across Agent, Merchant, and Admin
  surfaces.

## Accessibility & Inclusion

Target WCAG 2.1 AA. Maintain readable contrast for text and interactive states,
visible keyboard focus, usable touch targets, reduced-motion behavior, and
language support across the main workflows.
